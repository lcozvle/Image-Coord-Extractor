
#(图片坐标拾取器)

一个轻量级的 Python GUI 工具，用于从截图中快速、连续地提取矩形区域的坐标 `(x1, y1, x2, y2)`。

主要适用于 **RPA 自动化脚本** (如 Selenium, PyAutoGUI)、**游戏脚本编写**以及**计算机视觉** (Object Detection) 的数据标注工作。

## ✨ 功能特性 (Features)

*   **智能计算 (Smart Calculation)**：无需严格按照“左上-右下”顺序点击。只要点击目标区域的任意 4 个边缘点，程序会自动计算出标准的包围盒 (Bounding Box)。
*   **连续多选 (Continuous Selection)**：支持连续选取多个区域。每点击满 4 个点，程序自动记录当前组数据并重置，无需重启程序即可开始下一组选取。
*   **可视化反馈 (Visual Feedback)**：
    *   点击时显示红色标记点和序号。
    *   区域确定后绘制绿色虚线框，避免重复选取。
*   **广泛兼容 (Compatibility)**：基于 `Pillow` 库，支持 `.png`, `.jpg`, `.jpeg`, `.bmp` 等所有常见图片格式。

## 🛠️ 安装依赖 (Prerequisites)

本项目依赖 Python 3 和 Pillow 库。`tkinter` 通常内置于 Python 安装包中。

```bash
pip install Pillow
```

## 🚀 使用指南 (Usage)

1.  **运行程序**：
    在终端中运行 Python 脚本：
    ```bash
    python coordinate_picker.py
    ```

2.  **选择图片**：
    程序启动后会弹出文件选择窗口，选择你需要提取坐标的截图。

3.  **选取坐标**：
    *   在图片上的目标区域点击 **4 个点**（通常是矩形的四个角，或者上下左右四个边界）。
    *   点击时会显示红色圆点标记轨迹。

4.  **查看结果**：
    *   当点击第 4 个点后，图片上会出现一个**绿色虚线框**，表示该区域已锁定。
    *   控制台（Terminal）会立即输出该区域的坐标数据。

5.  **循环操作**：
    *   你可以直接继续在图上点击新的 4 个点来选取下一个区域。
    *   完成后直接关闭窗口退出程序。

## 📝 输出示例 (Output Example)

程序会在控制台按以下格式输出每一组的坐标：

```text
=== 第 1 组区域完成 ===
x1 (Left)   : 100
y1 (Top)    : 200
x2 (Right)  : 350
y2 (Bottom) : 400
数据元组    : (100, 200, 350, 400)
---------------------------

=== 第 2 组区域完成 ===
x1 (Left)   : 500
y1 (Top)    : 100
x2 (Right)  : 600
y2 (Bottom) : 150
数据元组    : (500, 100, 600, 150)
---------------------------
```

*   `x1, y1`: 区域左上角坐标
*   `x2, y2`: 区域右下角坐标
